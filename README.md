# Aashik Mahato | Portfolio Website

## Overview

This is the professional portfolio website of **Aashik Kumar Mahato**—an Electronics Engineering student, full-stack developer, and technology enthusiast. The site showcases skills, key projects, academic background, and core values with a focus on modern design and interactivity.

## ✨ Features

- **Mobile-First, Responsive Design:** Looks great on all devices.
- **React-Based UI:** Built with modern React for a smooth, dynamic experience.
- **Interactive Project Gallery:** Highlights featured and recent projects with rich detail.
- **Skills & Expertise:** Visual display of web, hardware, and software proficiencies.
- **Academic Timeline:** Interactive academic journey with highlights.

- **SEO & Social Sharing:** Optimized meta tags and OpenGraph support.

## 📦 Getting Started

Clone the repository and run locally:

```bash
git clone https://github.com/Aashik9567/Portfolio-website.git
cd Portfolio-website
npm install
npm run dev
```

Then visit [http://localhost:5173](http://localhost:5173) in your browser.

## 🔐 Environment Variables

Create a `.env` file (see `.env.example`) for local development.

- `VITE_GROQ_API_KEY` (used by the AI chatbot)
- `VITE_EMAILJS_SERVICE_ID`, `VITE_EMAILJS_TEMPLATE_ID`, `VITE_EMAILJS_PUBLIC_KEY` (used by the Contact form)

## 📂 Project Structure

  components/    # React components (About, Projects, HomePage, Skills, etc.)

public/

## ✍️ Customization

- Update profile info and images in `/src/assets` and `/src/components`.
- Add your projects in `Projects.jsx`.
- Tweak colors or styles in `index.css`.
